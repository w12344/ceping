# 飞书应用包：人才三大主属性测评

这个目录是一版可部署为飞书「网页应用」的前端包。

## 文件说明

- `index.html`：测评网页入口，可直接部署为静态网页
- `icon.svg`：应用图标，可用于飞书应用后台上传
- `feishu-app-config.example.json`：飞书应用配置参考

## 推荐发布方式

### 1. 先部署为 HTTPS 静态网页

把整个 `feishu-talent-app` 目录上传到公司可访问的静态网页空间，例如：

- 公司内网静态页面
- 阿里云 OSS / 腾讯云 COS / 七牛云静态网站
- Vercel / Netlify / GitHub Pages
- 公司已有前端发布平台

最终需要得到一个 HTTPS 地址，例如：

```text
https://your-domain.example.com/talent-assessment/index.html
```

飞书网页应用通常不能直接使用本地 `file://` 地址，需要可访问的 HTTPS 链接。

### 2. 在飞书开放平台创建应用

在飞书开放平台创建企业自建应用，应用名称建议：

```text
人才三大主属性测评
```

应用类型选择网页应用或 H5 应用，把应用首页地址配置为上面的 HTTPS 地址。

桌面端和移动端可以使用同一个地址：

```text
https://your-domain.example.com/talent-assessment/index.html
```

### 3. 配置可见范围并发布

建议先设置为小范围测试成员可见，例如 HR、研发负责人、几个试点团队成员。

确认体验正常后，再扩大到全员或指定组织。

## 当前版本的数据说明

当前测评结果只在员工浏览器本地计算，不会自动上传到服务器或飞书。

如果后续要做团队画像统计，可以升级为：

- 员工点击“提交结果”写入飞书多维表格
- 或接入后端服务，把结果写入数据库
- 或接入飞书机器人，把结果发送给指定管理员

## 后续可升级能力

- 飞书登录识别员工身份
- 结果提交到多维表格
- 团队维度统计看板
- 部门/岗位/项目组分布分析
- 管理者查看团队三大主属性比例和六大分型结构
