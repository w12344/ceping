# 人才三大主属性测评设定记录

## 当前用途

用于员工自测和团队分析，围绕三大主属性与六大分型：

- 进取者 Fighter：目标、行动、突破
- 思辨者 Thinker：分析、结构、创造
- 赋能者 Helper：连接、支持、稳定

六大分型：

- 冲刺型 Runner
- 攻坚型 Climber
- 分析型 Analyzer
- 创构型 Builder
- 人际型 Socializer
- 流程型 Keeper

## 当前测评版本

文件：

- `outputs/talent-assessment.html`

题量：

- 总计 42 题
- 六个分型各 7 题
- 每个分型 4 道正向题、3 道反向题

作答方式：

- 1-5 分量表
- 1 表示非常不符合
- 5 表示非常符合
- 反向题自动反向换算：1 -> 5，5 -> 1

画像规则：

- 绿色内核：4-5 分，代表稳定特质
- 黄色外核：2-5 分，代表整体倾向
- 每个分型满分为 35 分

结果逻辑：

- “你的当前倾向”先按三大主属性总分判断
- 再在该主属性内部选择更高的具体分型
- “主分型 / 次分型 / 第三倾向”按六大分型全局分值排名
- 如果三大主属性并列，会显示并列主属性，但当前分型仍保持与选定主属性一致

体验设计：

- 题目顺序每次打开随机打乱，降低刻意伪装类型的可能
- 题目表达尽量使用“工作偏好/行为习惯”，避免好坏判断
- 去掉“武士、法师、道士”等游戏角色解释，避免歧义
- 侧边栏只保留三大主属性说明，不显示外核解释
